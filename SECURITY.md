# Security Policy

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting for `tquoctuan97/jira-cli` and include:

- the affected command and version;
- reproduction steps or a minimal proof of concept;
- the expected security boundary and observed impact;
- whether credentials or private Jira data may have been exposed.

Do not include live PATs, credentials, private Jira content, or personal data in
the report. Use synthetic fixtures and redact logs before attaching them.

The maintainer will acknowledge the report, assess affected versions, and
coordinate disclosure after a fix is available.

## Supported versions

Until version 1.0, only the latest published release receives security fixes.
